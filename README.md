# dental-clinic-sql-analysis
SQL analysis of dental clinic visits, treatment frequency, and revenue using PostgreSQL

## Proyect Overview
This project analyzes dental clinic visit data using SQL and PostgreSQL.
The goal of this project is to practice SQL skills by answering basic business questions about dental treatments, visit cost, and revenue.

## Tools Used

- PostgreSQL 
- pgAdmin
- SQL
- Github

## Dataset
The dataset contains 10 dental visits with information about :
- Visit ID
- Patient ID
- Treatment
- Cost

## Analysis
The following questions were analyzed using SQL:
1. What is the total revenue?
2. What is the average visit cost?
3. How many visits are there for each treatment?
4. How much revenue does each treatment generate?
5. What is the most expensive individual visit?
6. what are the most common treatments?

## Key Findings

- The clinic recorded 10 dental visits.
- Total revenue was $1,870.
- The average visit cost was $187.
- Cleaning and filling were the most common treatments, with 4 visits each.
- The most expensive individual visit was an extraction costing $350.
